Установка на Android

  1. Скачайте верхний APK. Он подходит почти всем телефонам; нижний нужен только старым 32-битным.
  2. Откройте файл из папки «Загрузки».
  3. Разрешите установку из этого источника, если система спросит.
  4. Play Protect может предупредить, что источник неизвестен — это нормально для сборки вне Google Play.

Сборка подписана отладочным ключом проекта. Обновление ставится поверх предыдущей — данные сохраняются.
